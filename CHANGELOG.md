# История версий

Раздел `## X.Y.Z` становится описанием релиза `vX.Y.Z` на GitHub. Пишите для пользователей навыка:
что изменилось и что им нужно сделать. Новые версии добавляйте сверху.

## 1.2.0

- Установка в Claude одним шагом: репозиторий стал маркетплейсом плагинов, плагин `sape-links-seo`
  сразу подключает Sape Links MCP.
- Готовые архивы навыка в каждом релизе: `sape-links-seo-claude-web.zip` для claude.ai
  и `sape-links-seo.zip` для других агентов.
- Списки Избранного: сохранение проверенных доноров и поиск по спискам.
- Арендные размещения (помесячная оплата) и чёткое разделение статейных и арендных форматов.
