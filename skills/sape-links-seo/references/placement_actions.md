# SEO-действия для управления размещениями (Sape)

> **Когда читать:** перед каждым вызовом `perform_placement_action`. У каждого действия здесь есть предусловие (текущий статус размещения) и финансовое последствие, поэтому сначала подтвердите намерение с пользователем — см. *Финансовые ограничения* в `SKILL.md`.

Все действия вызываются через один инструмент:

```
perform_placement_action(placement_ids=[PLACEMENT_ID, ...], action="ACTION_NAME")
```

`placement_ids` — это **список**; можно действовать сразу по нескольким размещениям. Замените `ACTION_NAME` одним из значений ниже.

> **Важно:** одно и то же имя действия (например, `terminate_seo`) работает **по-разному** для статейных и арендных размещений. Платформа сама определяет тип размещения и применяет соответствующий workflow.

---

## Статейные размещения (разовая оплата)

| Действие                        | Описание                                                                                                                | Из статуса(ов)                                                                                | В статус                        | Примечания                                                                                                                  |
|---------------------------------|-------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|---------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| `approve_seo`                   | Одобрить размещение после проверки живой страницы. Помечает размещение как успешно завершённое.                         | `STATUS_PLACEMENT_CHECK`                                                                      | `STATUS_APPROVED`               | Доступно только на финальной стадии проверки.                                                                               |
| `approve_content_seo`           | Принять контент от вебмастера (для форматов, требующих одобрения контента).                                              | `STATUS_ON_CONTENT_APPROVAL`, `STATUS_PLACEMENT_ARBITRATION`                                  | `STATUS_ON_PLACEMENT_GUARANTEED`| После одобрения размещение переходит в гарантированное состояние. Обычно для форматов `review`, `link` или `archive`.       |
| `approve_from_arbitration_seo`  | Одобрить размещение, переданное в арбитраж, разрешая спор в пользу рекламодателя.                                        | `STATUS_PLACEMENT_ARBITRATION`                                                                | `STATUS_APPROVED`               | Используется, когда модератор или система решает в пользу рекламодателя.                                                    |
| `cancel_from_on_placement_seo`  | Отменить размещение в состоянии «на размещении» (до публикации вебмастером).                                              | `STATUS_ON_PLACEMENT`                                                                         | `STATUS_REJECTED`               | Доступно только в течение 1–72 часов после входа в `STATUS_ON_PLACEMENT`. Через 72 часа становится недоступным.             |
| `cancel_from_improve_seo`       | Отменить размещение в состоянии «требуется доработка» (вебмастер переделывает контент).                                  | `STATUS_PLACEMENT_IMPROVE`                                                                    | `STATUS_REJECTED`               | Разрешено, только если размещение находится в `STATUS_PLACEMENT_IMPROVE` более 15 дней.                                     |
| `cancel_seo`                    | Универсальная отмена для размещений в разных состояниях, где процесс застопорился или вы недовольны.                     | `STATUS_MODER`, `STATUS_CLARIFICATION`, `STATUS_ON_PLACEMENT_GUARANTEED`, `STATUS_NEED_APPROVE` | `STATUS_REJECTED`               | Требует, чтобы размещение было гарантированным и выполнялось условие таймаута.                                              |
| `terminate_seo`                 | Запросить постоянное удаление уже одобренного бэклинка.                                                                  | `STATUS_APPROVED`                                                                             | `STATUS_TO_TERMINATE`           | Ссылка удаляется после того, как вебмастер отработает запрос.                                                               |
| `cancel_order_change_links_seo` | Отменить заказ на изменение ссылок.                                                                                      | `STATUS_CHANGE_REQUESTED`                                                                     | `STATUS_APPROVED`               | Доступно в течение 7 дней после заказа изменения.                                                                           |

### Замечания по workflow (статейные)

- **Гарантированные размещения** (`STATUS_ON_PLACEMENT_GUARANTEED`) — те, по которым вебмастер подтвердил готовность выполнить работу. Большинство действий с гарантированными размещениями имеют более жёсткие таймауты — проверяйте колонку *Примечания* перед действием.
- **Арбитраж** (`STATUS_PLACEMENT_ARBITRATION`) — спорное состояние. Сначала попробуйте решить вопрос с вебмастером; если не разрешится — используйте `approve_from_arbitration_seo` или передайте решение модератору.

## Арендные размещения (помесячная оплата)

Жизненный цикл арендных ссылок **существенно проще** статейных: нет модерации, проверки размещения, арбитража или доработок. Основной цикл — создание → одобрение → активно (STATUS_APPROVED) → заморозка/удаление.

| Действие                      | Описание                                                          | Из статуса(ов)                                                                  | В статус                | Примечания                                                                                          |
|-------------------------------|-------------------------------------------------------------------|---------------------------------------------------------------------------------|-------------------------|-----------------------------------------------------------------------------------------------------|
| `approve_seo`                 | Одобрить созданную ссылку (обычно из авторежима).                  | `STATUS_NEED_APPROVE`                                                           | `STATUS_APPROVED`       | Ссылка становится активной, начинается ежемесячное списание.                                        |
| `sleep_manual_seo`            | Заморозить ссылку — приостановить списание.                       | `STATUS_APPROVED`, `STATUS_ERROR`                                               | `STATUS_SLEEP_MANUAL`   | Ссылка перестаёт работать, но не удаляется. Списание приостановлено.                                |
| `unsleep_manual_seo`          | Разморозить ссылку — возобновить списание.                        | `STATUS_SLEEP_MANUAL`, `STATUS_SLEEP_BILLING`                                   | `STATUS_APPROVED`       | Требует достаточный баланс. Если баланс нулевой — действие не пройдёт.                              |
| `order_change_links_texts_seo`| Запросить смену текста активной ссылки.                           | `STATUS_APPROVED`                                                               | `STATUS_CHANGE_REQUESTED` | Только для типа `rent`. Вебмастер получит запрос на изменение анкора.                              |
| `terminate_seo`               | Немедленно удалить арендную ссылку.                               | `STATUS_NEED_APPROVE`, `STATUS_ON_PLACEMENT`, `STATUS_APPROVED`, `STATUS_SELF`, `STATUS_ERROR`, `STATUS_SLEEP_MANUAL`, `STATUS_SLEEP_BILLING` | `STATUS_TERMINATED` | В отличие от статейных — удаляет **напрямую**, без промежуточного `STATUS_TO_TERMINATE`. Прекращает списания. |
| `force_billing_seo`           | Досрочная оплата — принудительно списать средства за период.      | Любой активный статус                                                           | (без изменения статуса)  | **Не разморозка.** Инициирует досрочный платёжный цикл. Не меняет статус размещения.                 |

### Замечания по workflow (арендные)

- **`STATUS_APPROVED` = активно и оплачивается.** Это нормальное рабочее состояние арендной ссылки. Ежемесячно списывается цена ссылки.
- **Заморозка по недостатку средств** (`STATUS_SLEEP_BILLING`) происходит автоматически, когда баланс исчерпан. Ссылка не удаляется — она «заморожена» и возобновится после пополнения баланса. Разморозить вручную можно через `unsleep_manual_seo` (если баланс позволяет).
- **`terminate_seo` — необратим.** Для арендных ссылок удаление происходит немедленно, без промежуточного статуса. Вебмастер получит уведомление, но ссылка уже неактивна.
- **Смена текста** (`order_change_links_texts_seo`) доступна только для арендных ссылок типа `rent` (блочные). После запроса ссылка переходит в `STATUS_CHANGE_REQUESTED`, где ожидает реакции вебмастера.

## Примеры

```
# Статейные: отменить размещение, застрявшее в «на размещении»
perform_placement_action(placement_ids=[12345], action="cancel_from_on_placement_seo")

# Арендные: одобрить созданную авторежимом ссылку
perform_placement_action(placement_ids=[67890], action="approve_seo")

# Арендные: заморозить ссылку (приостановить списание)
perform_placement_action(placement_ids=[67890], action="sleep_manual_seo")

# Арендные: разморозить ссылку после пополнения баланса
perform_placement_action(placement_ids=[67890], action="unsleep_manual_seo")

# Арендные: удалить ссылку навсегда
perform_placement_action(placement_ids=[67890], action="terminate_seo")
```

## Частые статусы

### Общие (статейные и арендные)

| Статус                          | Значение                                                        |
|---------------------------------|-----------------------------------------------------------------|
| `STATUS_PHANTOM`                | Начальное фантомное состояние перед любой обработкой.           |
| `STATUS_CREATING`               | Размещение создаётся в подсистемах.                             |
| `STATUS_NEED_APPROVE`           | Ждёт одобрения рекламодателя (режим авто-закупки).              |
| `STATUS_ON_PLACEMENT`           | Ожидается, что вебмастер разместит ссылку.                      |
| `STATUS_APPROVED`               | Размещение активно. Для статейных — завершено; для арендных — идёт ежемесячное списание. |
| `STATUS_CHANGE_REQUESTED`       | Запрошено изменение (ссылки / текстов).                         |
| `STATUS_ERROR`                  | Ошибка размещения.                                              |
| `STATUS_TERMINATED`             | Ссылка удалена.                                                 |

### Только статейные

| Статус                          | Значение                                                        |
|---------------------------------|-----------------------------------------------------------------|
| `STATUS_ON_PLACEMENT_GUARANTEED`| Вебмастер гарантировал размещение.                              |
| `STATUS_ON_CONTENT_APPROVAL`    | Контент готов к проверке рекламодателем.                        |
| `STATUS_PLACEMENT_CHECK`        | Живая страница проверяется системой.                            |
| `STATUS_PLACEMENT_IMPROVE`      | Вебмастер должен доработать размещение.                         |
| `STATUS_PLACEMENT_ARBITRATION`  | Идёт разрешение спора.                                          |
| `STATUS_TO_TERMINATE`           | Запрошено удаление ссылки (промежуточный статус).               |
| `STATUS_MODER`                  | На модерации.                                                   |
| `STATUS_CLARIFICATION`          | Требуется уточнение.                                            |
| `STATUS_BUY_FAIL`               | Попытка покупки не удалась.                                     |
| `STATUS_WAIT_WITHDRAWAL`        | Черновик ожидает оплаты.                                        |
| `STATUS_REJECTED`               | Размещение отклонено / отменено.                                |
| `STATUS_DELETED`                | Навсегда удалено.                                               |

### Только арендные

| Статус                          | Значение                                                        |
|---------------------------------|-----------------------------------------------------------------|
| `STATUS_SLEEP_MANUAL`           | Ссылка заморожена вручную (`sleep_manual_seo`). Списание приостановлено. |
| `STATUS_SLEEP_BILLING`          | Ссылка заморожена автоматически из-за недостатка средств.       |
| `STATUS_SELF`                   | Самоссылка (не оплачена).                                       |
