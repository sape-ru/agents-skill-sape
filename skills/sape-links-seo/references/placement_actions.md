# Действия с размещениями и статусы (Sape)

> **Когда читать:** перед каждым вызовом `perform_placement_action`. У каждого действия есть условие (в каком статусе должно быть размещение) и денежные последствия, поэтому сначала согласуйте действие с пользователем — см. правила трат (блок «Правила Sape для агентов») в `SKILL.md`.

Все действия вызываются через один инструмент:

```
perform_placement_action(placement_ids=[PLACEMENT_ID, ...], action="ACTION_NAME")
```

`placement_ids` — это **список**: можно применить действие сразу к нескольким размещениям, если все они в подходящем статусе. Замените `ACTION_NAME` одним из значений ниже.

> **Важно:** одно и то же имя действия (например, `terminate_seo`) работает **по-разному** для статейных и арендных размещений. Платформа сама определяет тип размещения.

---

## Статейные размещения (разовая оплата)

| Действие                        | Описание                                                                                                                | Из статуса                                                                                    | В статус                        | Примечания                                                                                                                  |
|---------------------------------|-------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|---------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| `approve_seo`                   | Одобрить размещение после проверки опубликованной страницы. Помечает размещение как успешно завершённое.                         | `STATUS_PLACEMENT_CHECK`                                                                      | `STATUS_APPROVED`               | Доступно только на финальной стадии проверки.                                                                               |
| `approve_content_seo`           | Принять контент от вебмастера (для форматов, требующих одобрения контента).                                              | `STATUS_ON_CONTENT_APPROVAL`, `STATUS_PLACEMENT_ARBITRATION`                                  | `STATUS_ON_PLACEMENT_GUARANTEED`| После одобрения размещение переходит в гарантированное состояние. Обычно для форматов `review`, `link` или `archive`.       |
| `approve_from_arbitration_seo`  | Одобрить размещение, переданное в арбитраж, разрешая спор в пользу рекламодателя.                                        | `STATUS_PLACEMENT_ARBITRATION`                                                                | `STATUS_APPROVED`               | Используется, когда модератор или система решает в пользу рекламодателя.                                                    |
| `cancel_from_on_placement_seo`  | Отменить размещение в состоянии «на размещении» (до публикации вебмастером).                                              | `STATUS_ON_PLACEMENT`                                                                         | `STATUS_REJECTED`               | Доступно только в течение 1–72 часов после входа в `STATUS_ON_PLACEMENT`. Через 72 часа становится недоступным.             |
| `cancel_from_improve_seo`       | Отменить размещение в состоянии «требуется доработка» (вебмастер переделывает контент).                                  | `STATUS_PLACEMENT_IMPROVE`                                                                    | `STATUS_REJECTED`               | Разрешено, только если размещение находится в `STATUS_PLACEMENT_IMPROVE` более 15 дней.                                     |
| `cancel_seo`                    | Универсальная отмена для размещений в разных состояниях, где процесс застопорился или вы недовольны.                     | `STATUS_MODER`, `STATUS_CLARIFICATION`, `STATUS_ON_PLACEMENT_GUARANTEED`, `STATUS_NEED_APPROVE` | `STATUS_REJECTED`               | Для гарантированных размещений (`STATUS_ON_PLACEMENT_GUARANTEED`) — только после истечения срока.                         |
| `terminate_seo`                 | Запросить постоянное удаление уже одобренной ссылки.                                                                  | `STATUS_APPROVED`                                                                             | `STATUS_TO_TERMINATE`           | Ссылка удаляется после того, как вебмастер выполнит запрос.                                                               |
| `cancel_order_change_links_seo` | Отменить заказ на изменение ссылок.                                                                                      | `STATUS_CHANGE_REQUESTED`                                                                     | `STATUS_APPROVED`               | Доступно в течение 7 дней после заказа изменения.                                                                           |

### Как это работает (статейные)

- **Гарантированные размещения** (`STATUS_ON_PLACEMENT_GUARANTEED`) — те, по которым вебмастер подтвердил готовность выполнить работу. Для них сроки действий строже — перед действием проверьте колонку «Примечания».
- **Арбитраж** (`STATUS_PLACEMENT_ARBITRATION`) — спор с вебмастером. Сначала попробуйте решить вопрос с вебмастером; если не разрешится — используйте `approve_from_arbitration_seo` или передайте решение модератору.

## Арендные размещения (помесячная оплата)

У арендных ссылок **намного меньше статусов**, чем у статейных: нет модерации, проверки размещения, арбитража и доработок. Обычный путь: создание → одобрение → активна (`STATUS_APPROVED`) → заморозка или удаление.

| Действие                      | Описание                                                          | Из статуса                                                                      | В статус                | Примечания                                                                                          |
|-------------------------------|-------------------------------------------------------------------|---------------------------------------------------------------------------------|-------------------------|-----------------------------------------------------------------------------------------------------|
| `approve_seo`                 | Одобрить ссылку, созданную автозакупкой.                  | `STATUS_NEED_APPROVE`                                                           | `STATUS_APPROVED`       | Ссылка становится активной, начинается ежемесячное списание.                                        |
| `sleep_manual_seo`            | Заморозить ссылку — приостановить списание.                       | `STATUS_APPROVED`, `STATUS_ERROR`                                               | `STATUS_SLEEP_MANUAL`   | Ссылка перестаёт работать, но не удаляется. Списание приостановлено.                                |
| `unsleep_manual_seo`          | Разморозить ссылку — возобновить списание.                        | `STATUS_SLEEP_MANUAL`, `STATUS_SLEEP_BILLING`                                   | `STATUS_APPROVED`       | Требует достаточный баланс. Если баланс нулевой — действие не пройдёт.                              |
| `order_change_links_texts_seo`| Запросить смену текста активной ссылки.                           | `STATUS_APPROVED`                                                               | `STATUS_CHANGE_REQUESTED` | Только для блочных. Вебмастер получит запрос на смену анкора.                                       |
| `terminate_seo`               | Немедленно удалить арендную ссылку.                               | `STATUS_NEED_APPROVE`, `STATUS_ON_PLACEMENT`, `STATUS_APPROVED`, `STATUS_SELF`, `STATUS_ERROR`, `STATUS_SLEEP_MANUAL`, `STATUS_SLEEP_BILLING` | `STATUS_TERMINATED` | В отличие от статейных — удаляет **напрямую**, без промежуточного `STATUS_TO_TERMINATE`. Прекращает списания. |
| `force_billing_seo`           | Досрочно списать оплату за период.                                | Любой активный статус                                                           | (без изменения статуса)  | **Это не разморозка.** Списывает деньги досрочно, статус не меняется.                               |

### Как это работает (арендные)

- **`STATUS_APPROVED` — ссылка работает и оплачивается.** Это обычное состояние арендной ссылки: каждый месяц списывается её цена.
- **Заморозка по недостатку средств** (`STATUS_SLEEP_BILLING`) происходит автоматически, когда баланс исчерпан. Ссылка не удаляется и снова заработает после пополнения баланса. Разморозить вручную можно через `unsleep_manual_seo` (если баланс позволяет).
- **`terminate_seo` — необратим.** Для арендных ссылок удаление происходит немедленно, без промежуточного статуса. Вебмастер получит уведомление, но ссылка уже неактивна.
- **Смена текста** (`order_change_links_texts_seo`) доступна только для блочных ссылок. После запроса ссылка переходит в `STATUS_CHANGE_REQUESTED` и ждёт ответа вебмастера.

## Прочие действия из списка инструмента

Эти действия есть в схеме `perform_placement_action`, но их условия и денежные последствия здесь пока не описаны. Перед использованием прочитайте актуальное описание инструмента, объясните пользователю, что, по-вашему, произойдёт, и получите явное подтверждение.

| Действие | Назначение (по названию) |
|---|---|
| `price_changing_action_accept_seo` | Принять изменение цены, предложенное по размещению |
| `delete_draft_seo` | Удалить черновик размещения (например, ожидающий оплаты, `STATUS_WAIT_WITHDRAWAL`) |
| `buy_from_buy_fail_seo` | Повторить покупку размещения в `STATUS_BUY_FAIL` |
| `delete_from_buy_fail_seo` | Удалить размещение в `STATUS_BUY_FAIL` |
| `guarantee_wm`, `accept_order_change_links_wm`, `price_changing_action_reject_wm` | Действия вебмастера; аккаунт рекламодателя ими обычно не пользуется |

`buy_from_buy_fail_seo` тратит деньги, как покупка: нужна свежая смета и подтверждение, правило «не повторять автоматически» действует.

## Примеры

```
# Статейные: отменить размещение, застрявшее в «на размещении»
perform_placement_action(placement_ids=[12345], action="cancel_from_on_placement_seo")

# Арендные: одобрить ссылку, созданную автозакупкой
perform_placement_action(placement_ids=[67890], action="approve_seo")

# Арендные: заморозить ссылку (приостановить списание)
perform_placement_action(placement_ids=[67890], action="sleep_manual_seo")

# Арендные: разморозить ссылку после пополнения баланса
perform_placement_action(placement_ids=[67890], action="unsleep_manual_seo")

# Арендные: удалить ссылку навсегда
perform_placement_action(placement_ids=[67890], action="terminate_seo")
```

## Частые статусы

### Общие (статейные и арендные)

| Статус                          | Значение                                                        |
|---------------------------------|-----------------------------------------------------------------|
| `STATUS_PHANTOM`                | Служебный начальный статус до обработки.           |
| `STATUS_CREATING`               | Размещение создаётся.                                           |
| `STATUS_NEED_APPROVE`           | Ждёт одобрения рекламодателя (автозакупка).              |
| `STATUS_ON_PLACEMENT`           | Ждёт, пока вебмастер разместит ссылку.                          |
| `STATUS_APPROVED`               | Размещение активно. Для статейных — завершено; для арендных — идёт ежемесячное списание. |
| `STATUS_CHANGE_REQUESTED`       | Запрошено изменение (ссылки / текстов).                         |
| `STATUS_ERROR`                  | Ошибка размещения.                                              |
| `STATUS_TERMINATED`             | Ссылка удалена.                                                 |

### Только статейные

| Статус                          | Значение                                                        |
|---------------------------------|-----------------------------------------------------------------|
| `STATUS_ON_PLACEMENT_GUARANTEED`| Вебмастер гарантировал размещение.                              |
| `STATUS_ON_CONTENT_APPROVAL`    | Контент готов к проверке рекламодателем.                        |
| `STATUS_PLACEMENT_CHECK`        | Система проверяет опубликованную страницу.                      |
| `STATUS_PLACEMENT_IMPROVE`      | Вебмастер должен доработать размещение.                         |
| `STATUS_PLACEMENT_ARBITRATION`  | Идёт разрешение спора.                                          |
| `STATUS_TO_TERMINATE`           | Запрошено удаление ссылки (промежуточный статус).               |
| `STATUS_MODER`                  | На модерации.                                                   |
| `STATUS_CLARIFICATION`          | Требуется уточнение.                                            |
| `STATUS_BUY_FAIL`               | Попытка покупки не удалась.                                     |
| `STATUS_WAIT_WITHDRAWAL`        | Черновик ожидает оплаты.                                        |
| `STATUS_REJECTED`               | Размещение отклонено / отменено.                                |
| `STATUS_DELETED`                | Навсегда удалено.                                               |

### Только арендные

| Статус                          | Значение                                                        |
|---------------------------------|-----------------------------------------------------------------|
| `STATUS_SLEEP_MANUAL`           | Ссылка заморожена вручную (`sleep_manual_seo`). Списание приостановлено. |
| `STATUS_SLEEP_BILLING`          | Ссылка заморожена автоматически из-за недостатка средств.       |
| `STATUS_SELF`                   | Самоссылка (не оплачена).                                       |
